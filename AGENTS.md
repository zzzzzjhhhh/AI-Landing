# Git workflow

For future user-requested code changes in this project, make a Git commit
after implementing and verifying the change. Report the commit ID and a
brief verification summary. Stage only files belonging to the current task;
never include unrelated or pre-existing worktree changes. If task changes
overlap pre-existing edits and cannot be isolated safely, preserve them and
explain the commit blocker. Do not treat this standing instruction as a
request to commit old work retroactively.
